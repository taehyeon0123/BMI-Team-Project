# TEAM9 BMI 프로그램

## 팀 소개 및 확인 사항
과제 화면의 팀장: 장태현(컴퓨터공학과). 팀원: 박지민(복지행정학전공), 김기범·전재균(컴퓨터공학과).
제공된 데이터에는 최민호가 포함되어 있으나 화면의 명단에는 없다. 포함 여부를 제출 전에 확인한다.
장태현의 키·몸무게·전화번호는 제공되지 않아 넣지 않았다. 필요하면 health.txt에 추가한다.

## 문제 및 설계
health.txt의 전화번호, 이름, 키(cm), 몸무게(kg)를 읽는다.
키를 m로 변환하고 BMI = 몸무게 / (키 / 100) ** 2로 계산한다.
반올림 전 값으로 소견을 결정하며 표에는 소수점 둘째 자리까지 출력한다.
소견 기준: 18.5 미만 저체중, 18.5 이상 23 미만 정상, 23 이상 25 미만 과체중, 25 이상 비만.
과제 예시의 BMI 값과 소견은 일관되지 않으므로 이 기준을 사용했다. 교수님이 별도 기준을 정했다면 opinion()을 수정한다.

## 역할 분담 제안
아래는 앞으로 수행할 분담이며 실제 수행 내역이 아니다. 제출 전에 실제 활동에 맞게 수정한다.

| 이름 | 담당 작업 |
|---|---|
| 장태현(팀장) | 코드 통합, GitHub 관리, README 정리, 최종 제출 |
| 박지민 | health.txt 데이터 정리, 누락·입력 형식 확인 |
| 전재균 | BMI 계산 및 소견 함수 검토, 계산값 확인 |
| 김기범 | Turtle 표 작성 및 글자·배치 확인 |
| 최민호(명단 확인 필요) | 실행 확인, result.png 캡처, 제출 파일 점검 |

## 파일 설명
- main.py: 파일 읽기, BMI 계산, Turtle 표 출력.
- health.txt: 전화번호 이름 키 몸무게를 공백으로 구분한 입력 파일.
- result.png: 실행한 Turtle 창을 캡처하여 추가할 파일. 현재 포함되지 않았다.

## 실행
Python 3와 tkinter/Turtle을 사용할 수 있는 데스크톱에서 실행한다. 추가 pip 패키지는 없다.
VS Code에서 이 폴더를 터미널로 열고 실행:

```bash
python main.py
```

Mac에서 python 명령이 없으면 python3 main.py를 사용한다.
GUI 없이 계산만 확인하려면 python main.py --check를 실행한다.
health.txt는 main.py와 같은 폴더에 둔다. 실행 위치와 무관하게 읽는다.

## 확인 결과와 남은 제출 작업
계산 결과: 박지민 20.68 정상 / 전재균 24.69 과체중 / 김기범 23.39 과체중 / 최민호 26.70 비만.
사용자가 제공한 최민호 BMI 26.40은 키 172cm, 몸무게 79kg으로 계산한 값과 달라 재계산했다.
GUI 화면은 제작 환경에서 실행·캡처하지 못했다. 본인 PC에서 실행해 표시 상태를 확인한다.
1. 실제 팀 명단과 팀장 데이터 확인.
2. 역할별 코드를 읽고 각자 맡은 부분을 확인한 뒤 실제 수행 내용과 소감 기록.
3. Turtle 창을 캡처하고 이 폴더에 result.png로 저장.
4. 팀장 GitHub에 homework/hw001 폴더 업로드. 전화번호가 있어 저장소 공개 범위는 팀원과 확인.
5. ZIP 이름을 HW01_BMI_TEAM9_장태현_실제제출일.zip으로 변경하고 캡처를 포함해 다시 압축.
6. 과제 화면의 지시에 따라 팀장 GitHub 링크와 ZIP을 제출.
